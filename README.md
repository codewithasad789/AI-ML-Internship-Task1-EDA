# Task 1: Exploratory Data Analysis on Iris Dataset

## Task Objective
Perform Exploratory Data Analysis on the Iris dataset to understand feature relationships and build classification models to predict Iris species.

## Dataset Used
Iris Dataset from Seaborn with 150 samples. Features: Sepal Length, Sepal Width, Petal Length, Petal Width. Target: Species.

## Models Applied
1. K-Nearest Neighbors (KNN)
2. Logistic Regression

## Key Results and Findings
Best Model: Logistic Regression with 97% accuracy. Petal Length and Petal Width are the most important features for classification.
